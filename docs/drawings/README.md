# Drawings

The drawings in the docs are generated by three scripts. Both use only the Python standard library.

| Script | Makes | From |
|--------|-------|------|
| [`make_panel_svg.py`](make_panel_svg.py) | `panel.svg`, used in the manual, and `panel-plain.svg`, the panel without captions, used on packaging labels | The faceplate KiCad file |
| [`make_assembly_svgs.py`](make_assembly_svgs.py) | `assembly-*.svg`, used in the assembly guide | The main PCB KiCad file |
| [`make_patch_svgs.py`](make_patch_svgs.py) | `patch-*.svg`, the patch examples in the manual | The faceplate KiCad file |

## Panel drawing

The panel drawing in the [user manual](../manual.md) ([`../images/panel.svg`](../images/panel.svg)) is generated from the KiCad faceplate file, [`PassiveMultiplesFaceplate.kicad_pcb`](../../PassiveMultiplesFaceplate/PassiveMultiplesFaceplate.kicad_pcb).

After changing the faceplate in KiCad, run this from anywhere in the repo:

```sh
python3 docs/drawings/make_panel_svg.py
```

### What it reads

| From the KiCad file | Used for |
|---------------------|----------|
| `Edge.Cuts` lines | Panel outline |
| Mounting-hole footprints and their drill sizes | Jacks (Ø6.0), the link button (Ø6.5) and the rack screw holes |
| `F.SilkS` lines, circles and text | Printed lines, the switch symbol and the labels |

The script tells holes apart by drill size, so if you change a hole size, update `JACK` and `SWITCH` at the top of the script. The "Bank A", "Bank B" and "Link button" labels are added by the script, not read from KiCad.

## Assembly drawings

After changing the main PCB in KiCad, run:

```sh
python3 docs/drawings/make_assembly_svgs.py
```

| Drawing | How it's made |
|---------|---------------|
| `assembly-1-switch.svg` | Front and back board views, drawn from the board outline, pads and front silkscreen in the PCB file |
| `assembly-2-cap.svg` | Hand-built side diagram, not from KiCad |
| `assembly-3-faceplate.svg` | Side diagram. The part positions along the board come from the PCB file, and the heights are approximate. |
| `assembly-4-jacks.svg` | Back board view, drawn from the PCB file |

The side views assume the faceplate sits 27 mm further along than the PCB, matching the two KiCad files. If you move the jacks on either board, update `offset` in `fig_faceplate`.

## Patch examples

The patch drawings reuse the panel drawing and add module boxes and cables. Each example is a short function in the script, for example:

```python
def pitch(data):
    p = Patch(data)
    p.source("A1", "Sequencer", "pitch CV out")
    p.dest("A2", "VCO 1", "V/oct in")
    ...
```

Jacks are named by bank and position from the top: `A1`–`A4` and `B1`–`B4`. Sources go on the left, destinations on the right. Pass `color=BLUE` to draw a second signal. To add an example, write a new function, add it to the list in `main()`, and run:

```sh
python3 docs/drawings/make_patch_svgs.py
```
